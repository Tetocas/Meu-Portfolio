# Políticas de Segurança do PortfolioHUB

## Objetivo

Definir práticas básicas de segurança para uso do repositório e publicação do PortfolioHUB.

## Práticas Implementadas

- Repositório público apenas com arquivos adequados para divulgação.
- Não inclusão de senhas, tokens, chaves de API ou dados sensíveis.
- Uso de commits descritivos para rastrear alterações.
- Revisão dos arquivos antes da publicação.
- Organização das permissões de acesso no GitHub.
- Compartilhamento apenas de links públicos necessários.

## Controle de Acesso

O acesso administrativo ao repositório é mantido apenas pelo proprietário da conta. Alterações futuras poderão ser realizadas por colaboradores autorizados, utilizando recursos do GitHub como branches e pull requests.

## Uso da IA Gemini

A IA Gemini foi utilizada como apoio para revisar boas práticas de segurança e orientar a documentação das políticas adotadas.
