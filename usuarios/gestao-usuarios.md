# Gestão de Usuários e Controle de Acesso

## Usuário Administrador

O PortfolioHUB possui um usuário administrador responsável pela manutenção do repositório e publicação do conteúdo.

## Controle de Acesso

Atualmente o repositório é público para consulta e visualização dos projetos.

As permissões de edição permanecem restritas ao proprietário do repositório.

## Colaboração

Caso sejam adicionados colaboradores futuramente, o controle será realizado por meio dos recursos do GitHub:

- Branches
- Pull Requests
- Revisão de código
- Histórico de commits

## Benefícios

Essas práticas garantem rastreabilidade, segurança e controle sobre as alterações realizadas no projeto.
